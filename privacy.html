隱私權說明

最近更新：2026 年 10 月 13 日

旅程智排是旅遊行程規劃工具。免登入模式將行程草稿與儲存的行程保留在你目前裝置的瀏覽器（localStorage），不會自動同步到雲端；瀏覽器資料清除後可能無法復原，建議下載 JSON 備份。

地圖與第三方資料服務

使用免費路由時，景點名稱、經緯度及路線請求會送至 OpenStreetMap 相關公開服務、OSRM、Nominatim 或 Overpass。選擇 Google Maps 模式後，瀏覽器會向 Google Maps Platform 發送路線請求；Google 可能依照其政策處理相關使用資訊。請參閱 Google 隱私權政策。

Google Maps API Key

使用者輸入的 Google Maps 瀏覽器金鑰只保存在目前瀏覽器，不會放進本網站的 GitHub 程式碼。瀏覽器金鑰會隨 Google API 網路請求傳送，請務必在 Google Cloud 設定來源網域、API 限制及配額，不要使用沒有安全限制的金鑰。可清除該網站瀏覽器儲存空間來刪除金鑰。

選用雲端同步

只有使用者主動註冊／登入 Supabase 並使用雲端儲存時，行程才會傳送至 Supabase。Supabase RLS 政策以使用者登入身分隔離資料。

其他

本站並非大型車導航或安全通行認證，規劃車程只是估計。若有使用說明相關疑問，可透過 GitHub 專案 聯繫維護者。
